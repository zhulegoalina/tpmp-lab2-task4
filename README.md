## Overview
Задание 4, вариант 37: "Государство".
Программа читает данные о странах из файла, обрабатывает и выводит:
- страны Европы с населением больше 8 млн жителей.
Структура: название страны, столица, язык, население, площадь, валюта, строй, глава, часть света.

## Usage
make && ./bin/lab2-task4

## Additional Notes
Структура проекта по модели КИС:
- `src/` — исходные файлы
- `include/` — заголовочные файлы
- `bin/` — исполняемые файлы
- `obj/` — объектные файлы
- `data/` — входные и выходные файлы
- `docs/` — документация и тесты
